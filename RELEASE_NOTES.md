Snapline is a native Windows screenshot clothesline inspired by Tendedero.

Download and extract **Snapline-Windows.zip**, keep `Snapline.exe.config` beside `Snapline.exe`, and run the executable. Requires Windows 10/11 and .NET Framework 4.8 or 4.8.1. The app is unsigned.

- Capture with **Ctrl+Shift+D** or the tray's **Take a snip** command.
- Reveal at the screen's top edge, with a natural drop and quick retraction.
- Click to copy, double-click to open, and hold to annotate.
- Slide photos along the rope to arrange them; pull down to share with other apps.
- Capture clipboard images and watch a screenshot folder.
- Keep images and layout locally across restarts.

Validated locally on Windows 11 Pro 25H2 x64. Mixed-DPI displays and Windows on ARM require further hardware testing. Image drop/paste support depends on the receiving app. See README for usage and limitations.
